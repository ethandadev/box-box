    Turn on telemetry in F1 25

    In the game: Settings → Telemetry Settings. Set these, then start any session.

    UDP TelemetryOn
    UDP Broadcast ModeOff
    UDP IP Address127.0.0.1
    UDP Port20777
    UDP Send Rate20Hz (or higher)
    UDP Format2026

    Waiting for the game… start a session (time trial is fine).

    Running the game on another PC or a console? Turn on “Accept telemetry from other devices” in Settings, and use this PC's IP address instead of 127.0.0.1.

    Wheel not detected? Use the game's own button binding

    In F1 25, bind a wheel button to UDP Action 1 (Settings → Controls), then click below. The game sends the press over telemetry.

    Test it: hold the button and say “radio check”. He should answer.

    Conversation optional

    Without an AI he still answers the common questions (gaps, tyres, fuel, weather, damage) instantly. With one he can talk strategy, rivals and your driving like a real engineer.
